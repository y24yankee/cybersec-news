1. Ghostjacking：毒化日志劫持 AI Agent，Cloudflare/Datadog/Sentry 均受影响

评分：93 分 | 来源：SecurityWeek / Tenet Security（DEF CON 2026 披露）

以色列初创公司 Tenet Security 在 DEF CON 2026 上演示了一种名为 "Ghostjacking" 的新型 AI 劫持攻击：攻击者将恶意指令以纯文本形式植入被拦截请求的日志中，当安全分析师让 AI Agent 审查事件时，Agent 会读取并执行这些指令。该攻击针对三个高信任平台——Cloudflare（路由全球 20% 流量）、Datadog（近半数财富 500 强使用）和 Sentry（约 400 万开发者使用）。在 Cloudflare 向量中，防火墙拦截的恶意请求被逐字记录到日志，Agent 读取后修改组织 DNS 设置指向攻击者域名，并报告"问题已解决"——对 Claude Code 的成功率高达 9/10。Datadog 向量利用前端密钥（已在互联网上发现 2,700+ 个），植入伪造"紧急诊断"告警，诱导 Agent 执行代码并外泄环境密钥和云凭据。Sentry 向量则通过伪造报告让 AI 助手 Seer 采纳恶意修复建议，传递给信任 Seer 的编码 Agent 执行。此外还发现了 Claude Desktop 数据外泄漏洞（Anthropic 已修复但未分配 CVE）。

评分理由： 新型 AI Agent 劫持攻击类别，DEF CON 正式披露，影响三大主流开发/运维平台，9/10 成功率，具有行业级威胁意义。

2. 波兰热电联产厂遭 IT→OT 跨界攻击，蒸汽轮机与水处理系统停机

评分：92 分 | 来源：Security Affairs / CERT Polska

波兰 CERT 发布报告披露：2025 年 12 月 29 日（与波兰大规模能源攻击同期），一家为约 5 万居民供热的小型热电联产厂（CHP）遭网络攻击，攻击者通过一条此前从未被观察到的路径——私有 APN——从 IT 网络渗透至 OT 网络。攻击链：攻击者首先入侵风场暴露在互联网上的 Fortinet VPN/防火墙设备 → 发现 Teltonika 蜂窝路由器 → 通过 SSH 建立隧道 → 到达配电网运营商管理的私有 APN → 接入工厂 OT 网络 → 找到 Wago PLC 并通过 SSH 访问 → 经过约一周侦察后连接 Siemens PLC → 将其切换至停止模式并设置密码锁定操作员。蒸汽轮机和水处理系统随即停机，热电联产中断，但工作人员较快恢复避免了供暖/供电中断。攻击者还破坏了 WAGO 控制器的分区表以覆盖痕迹（设备无法通过恢复出厂设置修复），并重新配置了 Moxa 串口服务器和交换机。ESET 以中等信心将该行动归因于俄罗斯 Sandworm APT。CERT 指出此类私有 APN 架构并不罕见，该发现具有超越波兰的普遍警示意义。

评分理由： 首次观察到的私有 APN 攻击向量，导致物理基础设施停机，5 万居民受影响，国家级 APT 归因，对全球能源行业具有标杆警示作用。

3. 朝鲜 Kimsuky 构建本地 LLM 武器库，将 AI 全面融入攻击链

韩国安全公司 Genians 在 8 月 10 日发布报告，揭示朝鲜侦察总局下属的 Kimsuky（APT43）黑客组织已从"用 AI 生成钓鱼诱饵"升级为"构建完整本地 AI 攻击基础设施"。调查显示该组织在受控服务器上部署并运行了 Ollama、GPT4All 和 Msty 等本地 LLM 运行环境（GPT4All 携带已配置的 localdocs_v3.db RAG 数据库），以及 Cursor AI 编码工具和语音转文字（STT）工具（如 OpenAI Whisper）。使用本地 LLM 的核心目的是避免将窃取的机密数据传输至云端 AI 服务，降低被监测风险。RAG（检索增强生成）被用于从窃取的文档中自动提取钱包详情、Gmail 凭据和网站注册历史等敏感信息。该组织还收集了大量 AI 开发库（LLaMaSharp、Microsoft.Extensions.AI、OpenAI、Azure.AI.OpenAI），构建从"本地 AI 执行 → 文档检索 → 自动化 Agent → 外部 AI 集成"的完整工具链。攻击行动被追踪为 "Operation GitPower"，使用 GitHub/GitLab 仓库作为 C2 基础设施。钓鱼诱饵已从回收利用合法文档升级为 AI 生成的虚拟资产投资报告和金融文件，语言自然、格式专业，难以通过内容检测识别。

评分理由： 国家级 APT 将 AI 从实验性使用推进到操作性集成阶段，本地 LLM + RAG + Agent 框架的完整武器化标志着 AI 驱动攻击的范式转变。

威胁组织入侵了 WordPress 高级插件开发商 BdThemes 的上游存储基础设施，通过篡改远程 JSON 数据流（促销横幅 API 响应），在管理员浏览器中注入恶意 JavaScript，利用 2026 年 3 月引入的 XSS 漏洞（Biggop Library 的 display_id 参数输出转义不足），使用管理员已认证会话静默创建流氓管理员账户并植入 Webshell（emer-run.php）。攻击完全由 API 驱动，无需文件修改或插件更新，每次管理员打开 wp-admin 页面时载荷自动执行。注入代码还操纵 WordPress 数据库查询以隐藏流氓账户，使其难以被发现。BdThemes 旗下产品（Element Pack、Prime Slider、Ultimate Post Kit、Pixel Gallery、Ultimate Store Kit）总计超过 35 万活跃安装，其中旗舰免费插件 Element Pack 在 WordPress.org 上显示超过 10 万活跃安装。Wordfence 从 8 月 7 日起通过 WAF 检测到攻击，分析确定最早可能始于 6 月 23 日。C2 基础设施指向此前 Advanced Responsive Video Embedder 和 OptinMonster 供应链攻击的同一攻击者。受影响插件已于 8 月 8 日从 WordPress.org 目录下架。

评分理由： 大规模 WordPress 供应链攻击，35 万+ 安装受影响，API 驱动的隐蔽攻击无需用户交互，与已知供应链攻击者关联。
