1. SiYuan 笔记应用 CVSS 10.0 未认证管理员接管漏洞（CVE-2026-66012）

评分：93/100 | 严重性：CVSS 10.0 Critical + 公开 PoC + 远程未认证 RCE | 来源：Rapid7 / VulnCheck / GitHub PoC

SiYuan v3.7.2 之前的版本在 POST /mcp 内核端点存在授权缺失漏洞，仅通过通用 model.CheckAuth 检查，未强制管理员角色或只读权限。当 Publish 服务器以匿名模式启用时，攻击者无需认证即可访问 31 个 MCP 工具（包括文件读写/删除/重命名），读取 conf/conf.json 提取 accessAuthCode、api.token、cookieKey 明文凭证，植入恶意插件实现 nodeIntegration:true 的桌面端 RCE。7 月 26 日已有 PoC 在 GitHub 公开，攻击链完整：MCP 握手 → 凭证窃取 → 插件植入 → 管理员接管。

评分理由： CVSS 10.0 满分 + 远程未认证 + PoC 已公开 + MCP 攻击面新颖，对自托管知识管理平台构成即刻威胁。

2. GitHub 和 PyPI 推出基于时间的供应链攻击防御机制

评分：88/100 | 严重性：行业级供应链安全基线变更 | 来源：BleepingComputer / GitHub Blog

GitHub 为 Dependabot 引入默认 72 小时冷却期——新版本发布后，版本更新 Pull Request 自动延迟 3 天生成，避免自动化工具在恶意包发布后的"黄金窗口"内将其拉入项目。同时 PyPI 宣布禁止向已发布超过 14 天的版本上传新文件，防止攻击者窃取发布令牌后向旧版本注入恶意代码。两项措施针对过去一年 chalk/debug 投毒、s1ngularity、Shai-Hulud、GhostAction 等多起重大供应链攻击。GitHub 数据显示：截至 2026 年 5 月的一年内，GitHub Advisory Database 发布了超过 6,500 条 npm 恶意软件告警（日均约 18 个），其中多数在发布后数小时内被检测到但未必能及时下架。安全更新（Security updates）不受冷却期影响，仍即时推送。

评分理由： 影响全球数百万开发者和项目的默认行为变更，从平台层面缩小了供应链攻击窗口。
