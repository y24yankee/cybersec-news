1. Metabase 零日 SQL 注入漏洞（CVSS 10.0）遭在野利用，Framework 与 Tally 客户数据被盗

评分：95 分 | 严重性：CVSS 10.0 零日，已在野利用，已确认数据泄露 | 来源：Bleeping Computer / RuntimeWire

Metabase 披露其云服务遭零日攻击，攻击者利用 /api/session/reset_password 端点的未授权 SQL 注入漏洞，向 Metabase 应用数据库注入任意 SQL 并获取实例管理员权限。管理员权限可更改配置、窃取已连接数据库的存储凭据、读取并导出数据。漏洞 CVSS 评分为满分 10.0，影响 0.58 及以上所有分支版本，自托管部署同样存在风险。笔记本电脑制造商 Framework 和表单构建工具 Tally 已确认数据被盗——Framework 客户的姓名、邮箱、IP、地址等信息于 8 月 3 日被访问，Tally 用户邮箱和密码哈希泄露。Metabase 已在所有受影响分支发布修复版本（0.58.24 / 0.59.21 / 0.60.17 / 0.61.11 / 0.62.9 / 0.63.5），并提供了 IoC 检测模式：POST /api/session/reset_password 返回 400 后紧跟成功 GET /api/user/current。

评分理由： CVSS 10.0 零日、已确认在野利用、已具名受害者数据泄露、影响 10 万+ 企业使用的 BI 平台及其连接的所有数据库。

3. 恶意软件可滥用 Windows Hello for Business 密钥实现 Entra ID 持久化访问——绕过钓鱼 resistant 认证

评分：91 分 | 严重性：绕过 phishing-resistant 认证，无需管理员权限，PoC 已公开 | 来源：The Hacker News

安全研究员 Dirk-jan Mollema 演示了已在受害者已登录 Windows 会话中运行的恶意软件，可静默使用受害者的 Windows Hello for Business (WHfB) 密钥向 Microsoft Entra ID 认证——无需管理员权限、无需触发生物识别提示、无需从 TPM 提取私钥。攻击者可借此建立持久云访问、注册受控设备、获取 Primary Refresh Token（有效期 90 天），甚至在策略允许时添加额外认证方式。关键技术突破：将 WHfB 密钥视为 FIDO2 passkey 通过 WebAuthn 使用，发现 Entra ID 的 5 分钟 challenge 未绑定到会话/用户/租户，因此攻击者可在另一台主机上请求 challenge 并让被入侵端点生成签名断言。该登录甚至满足 Conditional Access 中"phishing-resistant authentication strength"策略要求。Microsoft 表示该行为"保持原样"不做修复。PoC 脚本已在 ROADtools GitHub 仓库公开。

评分理由： 直接绕过 Microsoft 力推的 phishing-resistant 认证体系，无需提权，PoC 已公开，影响所有使用 WHfB 的 Entra ID 环境，Microsoft 拒绝修复。

5. Linux SCTP 18 年老漏洞（SCTPhantom, CVE-2026-64564）可获取 Root 权限并逃逸容器

评分：89 分 | 严重性：本地提权 + 容器逃逸，影响 2008 年以来所有 Linux 内核 | 来源：The Hacker News

腾讯朱雀实验室披露 Linux SCTP 网络代码中一个存在 18 年的 use-after-free 漏洞（CVE-2026-64564，命名为"SCTPhantom"），可被利用获取主机 root 权限并逃逸容器。漏洞源于动态地址重配置中的身份混淆：内核用数据包源地址校验删除请求，但实际操作的路径是根据消息内另一个地址选取的——一条消息携带地址、该地址的删除请求和通配符删除即可触发释放后重用。该漏洞自 Linux 2.6.25（2008 年）起存在于所有内核版本。研究人员在 Debian 13、Ubuntu 24.04、Rocky Linux 9、RHEL 9 和 OpenCloudOS 上测试，容器逃逸成功率达 6/8（75%），且保持默认 seccomp 配置、未授予 CAP_NET_ADMIN 或 CAP_SYS_ADMIN。修复已包含在 8 月 3 日发布的稳定内核 7.1.6、6.18.42、6.12.101 和 6.6.148 中。漏洞由腾讯自研多智能体研究管线 Corvus AI 发现，是近期 AI 辅助发现的系列休眠内核漏洞之一。

评分理由： 18 年老漏洞影响所有 Linux 内核，容器逃逸成功率 75%，由 AI 研究管线发现，凸显 AI 在内核漏洞挖掘中的加速效应。
