4. NoisyTCP：潜伏 11 年的 Linux 内核漏洞可无认证远程崩溃 Nginx / Apache / SSH 服务器

  • 评分：88
  • 来源： BleepingComputer（2026-11-16，研究员 Hyunwoo Kim）
  • 摘要： 一个沉寂约 11 年的 Linux 内核缺陷 CVE-2026-99288（NoisyTCP）被披露，影响几乎所有 Linux 发行版。该漏洞源于 TCP 无锁连接查找中的竞态：回收的 socket 内存在正确初始化和哈希前被访问，未认证攻击者可通过特制 TCP 包利用 SYN cookie 处理与 socket 哈希之间的时序触发 NULL 指针解引用，导致内核崩溃（DoS）。由于缺陷位于内核网络路径而非单个应用，默认配置下运行 Nginx、Apache 或 SSH 的服务器均可被远程打瘫；不过竞态窗口较窄，需多 RX 队列或 RPS 环境，且不会造成数据篡改或代码执行。修复已合入主线内核，无法立即打补丁者可临时禁用 SYN cookie 并改为单 RX 队列。
  • 评分理由： 影响面几乎覆盖全部 Linux 发行版、默认配置即可被无认证远程触发，历史跨度长、新颖性与影响范围突出（仅 DoS 略减分）。
