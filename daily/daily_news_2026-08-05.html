1. ChainDrop/npm 蠕虫感染 1,300+ 包、20 亿月下载量，窃取全栈凭据并植入 Claude Code / VS Code 钩子

评分：94 分 | 严重性：供应链蠕虫 + 全栈凭据窃取 | 新颖性：自传播蠕虫 + AI 开发工具持久化 | 影响范围：1,300+ 包 / 20 亿月下载 / 9 个组织

自传播恶意软件 ChainDrop（Shai-Hulud 蠕虫家族）于 8 月 4 日大规模爆发，起因是 Keyv 维护者的 GitHub 账户被攻破，恶意代码随后通过 npm 发布机制自动扩散至 Deliveroo、Ornikar、OneReach、Picsart、Qlik、ServiceTitan 等组织的包中。Aikido 确认至少 868 个包 / 1,381 个版本被感染，SafeDep 更新计数达 1,684 个恶意版本 / 420 个包名。

蠕虫通过 preinstall 脚本执行 setup.mjs，下载 Bun 运行时并执行 Math_Symbol.js 信息窃取载荷，收集 GitHub PAT、npm token、AWS 凭据、Kubernetes secrets、HashiCorp Vault token、数据库凭据、Stripe/Slack/Twilio/Azure/GCP 凭据等，加密后外泄至描述为 "Shai-Hulud: Here We Go Again" 的公开 GitHub 仓库。此外，Keyv 仓库中被植入了 .claude/settings.json（SessionStart 钩子）和 .vscode/tasks.json（folderOpen 任务），可在开发者信任工作区后触发载荷执行。

值得注意：被感染的包携带有效的 OIDC 和 SLSA 来源证明，因为它们通过了项目合法的 GitHub Actions 发布流程——来源验证无法检测源代码被篡改。npm 12 默认禁用未批准的生命周期脚本，但旧版本客户端仍受影响。

2. CISA 将 IBM Langflow CVE-2026-9198（CVSS 9.8）列入 KEV —— AI Agent 平台无认证 RCE 已在野利用

评分：92 分 | 严重性：CVSS 9.8 无认证 RCE | 新颖性：AI 基础设施 0day | 影响范围：所有互联网暴露的 Langflow 实例 | 时效性：KEV 当日新增

CISA 于 8 月 4 日将三个漏洞加入已知被利用漏洞（KEV）目录，其中最严重的是 IBM Langflow OSS 的 CVE-2026-9198（CVSS 9.8）。该漏洞利用链为：调用未认证的 /api/v1/auto_login 端点获取超级用户 token，再用该 token 访问 /api/v1/validate/code 通过 exec() 执行任意 Python 代码，在默认部署下实现完全的远程代码执行，无需任何凭据。

Langflow 是团队用于搭建 AI Agent 的低代码工具，影响版本为 OSS 1.0.0 至 1.10.0，修复版本为 1.10.1。此前已有攻击者利用暴露的 Langflow 实例进行加密货币挖矿（6 月）和 AI Agent 自主勒索软件攻击（7 月），此次 KEV 列入确认了持续利用模式。同批加入 KEV 的还有 Apache Tomcat CVE-2026-34486（CVSS 7.5，EncryptInterceptor 绕过）和 N-able N-central 认证绕过漏洞。

3. Google 删除 3 个 ADK AI 工作流 —— 公开 GitHub Issue 即可操纵 AI Agent 越权触发特权工作流

评分：88 分 | 严重性：CI/CD 凭据泄露 + 任意代码执行 | 新颖性：GitHub Issue → AI Agent 提示注入 → 特权越权 | 影响范围：Google 官方仓库

Pillar Security 发现 Google Agent Development Kit (ADK) Python 仓库存在 AI Agent 权限边界缺陷：攻击者只需提交一个公开 GitHub Issue，即可通过提示注入操纵公开的分诊 Agent（issue-analyze.yml），使其以 adk-bot 身份发布 /adk-issue-fix 命令。由于 adk-bot 被识别为协作者，该命令通过了特权工作流（issue-fix.yml）的 owner/member/collaborator 权限检查——受信任的 bot 身份成为了授权桥梁。

研究人员在 CI runner 上实现了任意代码执行，并窃取了 bot 的个人访问令牌（PAT）、Google API 密钥和 GCP 服务账号凭据。特权任务还持有对 issues、仓库内容和 PR 的写权限。攻击路径通过 Git hooks（core.hooksPath）绕过了命令允许列表（仅允许 gh 和 git 命令）。

Google 已删除 issue-analyze.yml、issue-fix.yml 和 pr-analyze.yml 三个工作流。该漏洞不影响已分发的 ADK Python 包本身，而是仓库自动化层面的缺陷。

来源： The Hacker News / Pillar Security

4. cPanel CVE-2026-58048（CVSS 9.4）—— 共享主机用户可以数据库 Root 权限执行 SQL，可延伸至 OS 级入侵

评分：86 分 | 严重性：CVSS 9.4 数据库权限提升 | 新颖性：数据库重命名流程的 SQL 模式丢失 | 影响范围：所有受支持的 cPanel & WHM 版本 + WP Squared

cPanel 修复了一个严重漏洞 CVE-2026-58048（CVSS 4.0: 9.4），允许已认证的共享主机客户在数据库 root 上下文中执行 SQL 命令，跨越 cPanel 账户与服务器管理数据库身份之间的权限边界。该漏洞位于数据库重命名流程中——重命名时 SQL 模式未被保留，导致 SQL 以 root 权限执行。根据操作系统和数据库引擎配置，这可能延伸至操作系统级别的入侵。

漏洞影响所有受支持的 cPanel & WHM 版本以及 WP Squared，需要有效的 cPanel 账户和 MySQL/MariaDB 功能访问权限。修复版本包括 11.110.0.137、11.118.0.71、11.126.0.78、11.134.0.48、11.136.0.32 和 WP Squared 138.1.6。临时缓解措施是撤销 cPanel 用户的 MySQL 功能。

同一安全版本还修复了 CVE-2026-58047（HTTP 请求走私，CVSS 5.6）和 Exim .forward 文件权限提升问题。CISA 8 月 4 日的丰富化记录评估其技术影响为"完全"（total）。

来源： The Hacker News / cPanel 安全公告

Manifold Security 发现 77 个 Open VSX 市场（VSCodium、Gitpod、Eclipse Che 等使用）上的"Evil Twin"扩展，它们仿冒 AMD、Azure、Salesforce、Hyperledger、LEGO Education、IOTA 甚至美国政府机构命名空间的合法扩展。所有 77 个扩展通过共享数据外泄域名 mangorbit[.]com（7 月 15 日注册）关联。

其中 58 个扩展仅发送主机名等少量系统信息，但另外 19 个在激活后约 4-5 秒收集大量数据：操作系统用户名、主机名、机器标识、编辑器版本、平台架构、时区、工作区完整路径，以及 .git 目录中的 Git 远程主机、组织、当前分支和 HEAD commit 哈希。它们还枚举最多 60 个已安装扩展，并收集 GitHub、GitLab、Azure DevOps、Buildkite、CircleCI、GitHub Codespaces 和 Gitpod 等 CI/CD 环境标识。

这些扩展在listing中披露收集"匿名使用指标"并声明不访问源代码或凭据，但实际发送的数据超出披露范围，包括可能暴露私有仓库名称或路径的 CI 信息。部分变体支持持续传输 7 天，并可通过 DNS TXT 记录获取备用外泄 URL。扩展已于 8 月 3 日从 Open VSX 移除，但需开发者手动从系统中删除。
